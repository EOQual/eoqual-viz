# eoqual-viz

Fonctions graphiques génériques communes aux modules (numpy/plotly seulement) : heatmap 2D interactive, galerie d'images, courbes multiples, comparaison de courbes/coupes avec repères verticaux — installé automatiquement avec les modules qui l'utilisent. Ne remplace pas pixoscope (application de visualisation autonome, pas une bibliothèque).
